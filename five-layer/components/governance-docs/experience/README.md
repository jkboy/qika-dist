# EXPERIENCE 层

EXPERIENCE 保存带明确试错链、但尚未稳定归位的短期教训。它不是通用知识库，也不是永久最佳实践库。

## 收录条件

同时满足：

- 有可复述的触发场景或失败现象。
- 至少记录一个无效方案和一个已验证有效方案。
- 下次遇到相同信号时能直接改变行动。
- 尚未稳定到足以进入 AGENTS、SKILL、KNOWLEDGE 或 HOOK。

只有一次观察、但可从事实源复查的内容应进入 KNOWLEDGE。普通任务日志留在 task 或 session。

## 召回

1. 任务出现错误关键字、工具名或相似现象时扫描 `INDEX.md`。
2. 只加载关键词命中的正文。
3. 命中后核对适用版本与边界，不能把旧经验当成当前事实。

Pi 不会自动读取本目录，因此每个运行态条目必须登记在 `INDEX.md`，或由 AGENTS / SKILL / extension 显式引用。

## 生命周期

- 再次命中：记录命中证据，评估是否应提升。
- 已可流程化：迁入 SKILL。
- 已成为可复查事实：迁入 KNOWLEDGE。
- 高频跨任务原则：迁入 AGENTS。
- 可确定性机械检测且遗漏代价高：迁入 HOOK。
- 已过时或可能误导：从索引移除并删除正文。

提升后必须清理原运行索引，避免同一规则多层并存。
