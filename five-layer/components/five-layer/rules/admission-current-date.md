# Hook 准入卡：current-date

- 规则 ID：current-date
- 已观察失败：模型做任务规划、搜索时间窗推理时，用训练知识截止日期推断"现在"，时间范围锚定错误（用户在游戏任务规划场景多次观察，2026-08-21 提出）。已核查 Pi 源码 `dist/core/system-prompt.js`：system prompt 不注入当前日期，失败为结构性数据缺口。
- 关联层与主源：HOOK 层，本规则即唯一主源。曾短暂落在全局 AGENTS.md「时间锚定」节（2026-08-21，同一会话内随本规则上线删除，AGENTS → HOOK 迁移；出处维护者 2026-08-21 的一次 pi 会话）。旧卡写的「2026-02」是笔误（2026-09-28 五层审计核正）。
- 事件：`before_agent_start`
- 确定性检测信号：无条件每轮触发，数据源为本机系统时钟；不匹配 prompt 语义（时间缺口在任何任务都可能隐性存在，关键词门控会漏报）。
- 策略：context
- 选择该策略的理由：根因是数据缺失而非行为违规，注入数据即根治；warn/block 无意义。
- 正例：新会话问"今年是哪年 / 最近一个月的范围"，模型按注入时间回答，不再落在知识截止年份。
- 反例：无时间语义的任务不受干扰（注入约 25 token/轮，作为 display:false 消息追加，不打断 prompt 前缀缓存）。
- 措辞探针（2026-09-28，prompt-audit 20260925 B9）：deepseek-v4.1-flash，「今年是哪年 / 最近一个月范围 / 带年份的搜索词」各 3 次——不注入 5/6 答成 2025；只给数据、数据 + 「以此为准，不要用训练知识推断」指令均 9/9。据此删去指令句，只保留数据（约 60→25 token/轮）。
- 错误策略：`allow`（dispatcher 捕获异常后仅 warn）
- 恢复路径：注入失败时模型仍可执行 `date` 命令兜底获取时间。
- 回滚方式：`rules/index.ts` 移除注册，或本规则 `enabled: false`。
- 退出或复核条件：Pi 原生在 system prompt 注入可靠当前时间后，删除本规则及准入卡。
