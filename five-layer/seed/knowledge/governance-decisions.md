# 治理决定日志

记录两类否定性结论：**评估后拒绝**进入五层的候选，以及落地后**因实测有害/误伤撤销**的内容。作用是给治理层补跨会话记忆：查重时缺席才真正意味着"没考虑过"，命中则不重复评估、不重新引入已知坏改动。

条目是**可推翻的判例，不是永久禁令**：命中已拒候选时，无新事实 → 引用该条直接带过；出现满足"推翻条件"的新事实 → 针对旧理由重新论证，推翻后把"决定"改为"已推翻（日期）"并注明去向，不删行。

## 写入规则（保持极轻）

1. 只记两类，其余不记：
   - 门禁评估后**明确拒绝**的候选（留在 task 候选区继续观察的是"未决"，不算拒绝）；
   - 从五层**撤销**已落地内容且原因是实测有害/误伤（自然过时下架走 `deprecated/`，不记）。
2. 每条一行：候选一句话、决定、理由一句话、推翻条件。写不进一行说明还没想清楚，先想清楚再记。
3. 接受的决定不记——其结果本身就留在五层与版本历史中可见。
